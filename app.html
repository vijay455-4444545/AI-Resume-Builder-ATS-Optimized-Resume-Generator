AI Resume Builder

ATS‑Optimized Resume Generator

An intelligent web application that transforms a user’s experience and target job description into tailored, ATS‑friendly resumes in seconds using large language models.

Features

  • Step‑by‑step resume creation flow
  • LLM‑powered bullet optimization and keyword matching
  • ATS scoring and multiple resume templates
  • PDF and DOCX export
  • Containerized with Docker, ready for CI/CD
Stack: Next.js • FastAPI • PostgreSQL • Docker • LLM APIs • CI/CD

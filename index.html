AI Resume Builder – ATS‑Optimized Resume Generator

An intelligent web application that transforms a user’s experience and target job description into tailored, ATS‑friendly resumes in seconds using large language models.

  • Built a Next.js frontend with a step-by-step resume creation flow
  • Implemented a FastAPI backend that uses LLMs to optimize bullets and match job keywords
  • Added ATS scoring, multiple templates, and PDF/DOCX export
  • Containerized with Docker and deployed with CI/CD

Stack: Next.js • FastAPI • PostgreSQL • Docker • LLM APIs • CI/CD
